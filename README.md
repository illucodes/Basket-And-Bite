# Basket & Bite — Online Food & Grocery Delivery Platform

A responsive, front-end web application simulating an end-to-end online ordering experience for local restaurants and daily grocery essentials.

## Features
* **Dual Catalog Browsing:** Switch seamlessly between local restaurant menus and categorized grocery items.
* **Interactive Cart & Checkout:** Add/remove items, adjust quantities dynamically, and simulate full order placement using structured client-side data.
* **Responsive Design:** Clean, mobile-friendly layout styled with custom CSS typography and layout grids.

## Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
